 Gerador de URL RTSP

Uma ferramenta simples e eficiente para técnicos e integradores de segurança eletrônica gerarem strings RTSP personalizadas para diversas marcas de câmeras e DVRs.

Funcionalidades

Seleção por Marca: Templates prontos para Intelbras, Hikvision, Uniview, GIGA, JFL e Vivotek.
Validação de IP: Alerta automático caso o usuário tente usar um IP local (192.168.x.x), reforçando a necessidade de IP externo ou DDNS para uso com a nuvem.
Formatação Automática: Garante que a URL seja gerada exatamente no padrão aceito pelo VMS.
Single File:** Funciona totalmente em um único arquivo HTML, sem dependências externas.

Como usar

1. Acesse o link do projeto (gerado pelo GitHub Pages).
2. Selecione a Marca do dispositivo.
3. Preencha os campos solicitados (Domínio, Porta, Usuário, Senha, etc.).
4. Clique em Gerar URL.
5. Copie o link gerado e cole nas configurações da plataforma beNuvem.

Notas de Segurança

* Este gerador roda inteiramente no seu navegador (**Client-side**).
* Nenhum dado digitado (como senhas ou IPs) é enviado para servidores ou armazenado pelo GitHub.
* Dica: Evite o uso de caracteres especiais (!@#$%*&) nas senhas das câmeras para garantir a compatibilidade máxima com o protocolo RTSP.
